# 🔐 IdentityHub – Enterprise Identity & Access Management Dashboard

IdentityHub is a modern enterprise-style Identity and Access Management (IAM) dashboard designed to visualize and manage users, applications, roles, permissions, authentication activity, API monitoring, and security events.

The project focuses on creating a clean, responsive, and user-friendly administrative interface inspired by enterprise platforms such as Cisco Control Hub.

---

## 🚀 Features

- 📊 **Dashboard Overview**
  - Active users
  - API requests
  - Security events
  - Recent activity

- 👥 **User Management**
  - View user information
  - Monitor user activity
  - Track user provisioning

- 🔑 **Roles & Permissions**
  - Role management
  - Permission tracking
  - Access control overview

- 🔐 **Authentication Monitoring**
  - Login activity
  - Authentication status
  - Security events

- 🌐 **Application Management**
  - Manage connected applications
  - Monitor application access

- 📡 **API Monitoring**
  - API request statistics
  - Authentication activity
  - API health overview

- 📋 **Audit Logs**
  - Track administrative actions
  - Monitor security-related events

- 🔎 **Smart Search**
  - Search users and activity
  - Filter complete activity rows based on search results

- 🌙 **Dark Mode**
  - Toggle between light and dark themes
  - Theme preference is stored locally

- 📱 **Responsive UI**
  - Designed for desktop and smaller screen sizes
  - Responsive sidebar navigation
